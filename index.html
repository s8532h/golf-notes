メモを編集

共通データ基盤（移行準備）

既存データは変更せず、現在の記録を共通形式のJSONとして書き出せます。移行前の保全・検証用です。

バックアップ・復元

追加したメモをJSONファイルに書き出せます。クラウド同期を使わない場合は、機種変更前にバックアップしてください。

「置き換える」は、この端末のGolf Notesデータをバックアップ内の記録で全面的に置き換えます。実行前に現在のデータをバックアップしてください。Supabase上のデータは変更しません。

Mac・iPhone間のクラウド同期

Supabaseの同期機能です。メモ・ラウンドは専用テーブルへ、練習・計測・飛距離・目標・攻略ノート・AI分析などは本人専用のgolf_user_dataへ同期します。追加テーブルの作成SQLを実行するまでは、その他のデータの同期は利用できません。同期を設定するまではクラウドへ送信しません。

初回セットアップ（Supabase）

同期を有効にする前に、GitHubの supabase/schema.sql を開き、内容をSupabase SQL Editorで実行してください。このSQLは4テーブル・RLS・IDベース同期関数を作成します。実行はユーザー自身が行い、このアプリからDBスキーマを変更することはありません。

同期の接続設定

接続設定はこのブラウザに保存されます。MacとiPhoneの両方で一度ずつ入力してください。

スイング大全

テーマ：振り子・体の回転・足の動きを連動させ、再現性のあるスイングを目指す。

本全体の核となる考え方

手先でクラブを操作するのではなく、クラブの自然な動きと体全体の連動を利用する。 本書の中心となる要素は「振り子」「回転」「足の動き」の3つ。

スイングの基本イメージ

足の動き → 体の回転 → クラブの振り子 → インパクト

これは本書の3つの土台を練習向けに並べた整理。実際のスイングでは各要素が連動する。

章ごとの要点

第1章｜振り子の動きをスイングに取り入れよう
  • クラブを腕力だけで操作せず、クラブの重さと振り子の動きを感じる。
  • 振り子の支点や軌道を安定させ、毎回同じ動きを再現する。
  • 手首は固めきらず、体の回転と合わせてクラブの動きを生かす。
第2章｜正しい回転を身につけよう
  • 背骨を軸に、上半身だけでなく体全体の向きを変える。
  • バックスイングからフォローまで回転をつなげる。
  • 回転差や腰まわりの張りを意識し、腕だけで振らない。
第3章｜足の動きを覚えよう
  • 足の動きで体重移動と回転を促す。
  • 左足の踏み込みを使い、下半身からスイングを連動させる。
  • 足の動きと体の回転を、ブランコのようなリズムでつなげる。
第4章｜ポジションごとの動きや形を覚えよう
  • アドレス、グリップ、テークバック、トップ、切り返し、インパクト、フィニッシュを確認する。
  • 各ポジションを個別に作るだけでなく、一連の動作としてつなげる。
  • 切り返しで急いで腕を振り下ろさず、下半身の動きとクラブの自然な動きを合わせる。
第5章｜クラブによる打ち方の違いを知ろう
  • クラブの長さ・ロフト・ボール位置に合わせて構えや振り幅を調整する。
  • ドライバー、FW、アイアン、ウェッジで同じ基本を使いつつ、打ち方を使い分ける。
  • ウェッジは振り幅を基準に距離を打ち分ける。
第6章｜絶対にやるべき目的別反復ドリル
  • 目的を決めてドリルを反復し、動きを体に覚えさせる。
  • 小さな振り幅や片手打ちで、クラブ・腕・体の役割を確認する。
  • 足踏みや一歩前フォローなどで、足と体の連動を練習する。
